# Diseño — Lovely Lab aplicado a Lovely Fit

Base clara crema/verde, editorial, mucho espacio, bordes finos, esquinas suaves, grilla y círculos discretos.

## Tokens (`app/globals.css`)
| Token | Valor | Uso |
|---|---|---|
| `--cream` | #FEF8EF | Fondo |
| `--surface` | #FFFDF8 | Tarjetas |
| `--offwhite` | #F5F2EA | Tarjetas suaves, botones secundarios |
| `--lab` | #435229 | Botones, acento principal (8,0:1 sobre crema) |
| `--deep` | #28311F | Barra de descanso, marca |
| `--ink` | #1A1A1A | Texto (16,5:1) |
| `--ink-2` | #5A6148 | Texto secundario — oliva oscurecido (6,1:1) |
| `--olive` | #7B8467 | Solo acentos/gráficos (3,7:1: no apto texto chico) |
| `--clay` | #B47C65 | Solo acentos/gráficos (3,3:1: no apto texto chico) |
| `--clay-ink` | #8A5843 | Acento en texto (5,6:1) |
| `--stone` | #C9C7BD | Bordes (1,6:1: nunca texto) |

## Tipografías (auto-hospedadas con @fontsource, funcionan offline)
- PT Sans Narrow Bold: títulos, métricas, botones.
- Inter: textos, formularios, navegación.
- EB Garamond Italic: detalles editoriales puntuales.

## Entrenamiento
Campos de 52 px, botón de serie 56×52, descanso fijo abajo, teclado numérico, sin depender de gestos.
